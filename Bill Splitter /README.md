🧾 Bill Splitter

A command-line Python program that calculates a group's total bill and determines how much each person should pay.

What it does

The program allows the user to:

-Enter the number of people sharing the bill
-Enter the bill either as a total or by categories
-Add a tip percentage
-Calculate the final amount
-Divide the bill among the group
-Concepts practiced
-User input
-Arithmetic operations
-while loops
-Conditional statements
-Type conversion
-Basic validation
